# 🛒 Calculadora de Descontos em Python

Este é um script simples em Python que calcula o valor do desconto e o total a pagar de uma compra com base em faixas de preço pré-definidas.

---

## 📌 Regras de Negócio

O desconto é aplicado automaticamente conforme o valor total da compra:

| Faixa de Valor | Desconto Aplicado |
| :--- | :---: |
| **Abaixo de R$ 200,00** | **5%** |
| **Entre R$ 200,00 e R$ 299,99** | **10%** |
| **A partir de R$ 300,00** | **15%** |
